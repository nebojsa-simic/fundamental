## Why

GGUF (GPT-Generated Unified Format) is the standard model file format for llama.cpp and the wider LLM inference ecosystem. Every quantized open-weight model ships as a .gguf file. The GPT demo needs to load weights from a GGUF file, but Fundamental has no GGUF support. This module provides a complete GGUF header parser, metadata query API, tensor lookup, and dequantization for the types used by GPT-OSS-20B: F32, Q8_0, and MXFP4.

## What Changes

- New `include/fundamental/gguf/gguf.h` — public API header
- New `src/gguf/gguf.c` — header parsing, metadata KV query, tensor info lookup
- New `src/gguf/gguf_dequant.c` — dequantization: Q8_0, MXFP4 to float32
- New `arch/gguf/windows-amd64/mmap.c` — memory-mapped file access (CreateFileMappingW + MapViewOfFile)
- New `arch/gguf/linux-amd64/mmap.c` — memory-mapped file access (mmap)
- New `tests/gguf/` — test suite with build scripts
- New `tests/gguf/test_data/` — minimal GGUF test file generated by a Python tool (10KB, no model weights)

## Capabilities

### New Capabilities

- `gguf`: GGUF file format parser. Opens .gguf files via memory mapping, exposes metadata key-value pairs (string, int, float, bool), provides tensor info (name, shape, type, byte offset, byte size), and dequantizes Q8_0 and MXFP4 tensors to float32 buffers.

## Impact

- New directories: `include/fundamental/gguf/`, `src/gguf/`, `arch/gguf/`, `tests/gguf/`
- Dependencies: memory (for allocations), string (for name comparisons)
- No breaking changes to existing APIs
- Deferred: Q4_K, Q6_K, IQ-quants (not present in GPT-OSS MXFP4 GGUF)
